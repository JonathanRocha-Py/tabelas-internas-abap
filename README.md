# 📊 Estudo: Tabelas Internas no ABAP

## 📌 Conceito
Tabelas internas são estruturas de dados temporárias que armazenam conjuntos de linhas com a mesma estrutura durante a execução de um programa ABAP. É uma das estruturas mais fundamentais e utilizadas no desenvolvimento SAP.

## 🎯 O que este código demonstra
- Declaração de estrutura e tabela interna
- Inserção de registros (APPEND)
- Percorrendo registros com LOOP
- Lendo e exibindo dados

## 💡 Como testar este código
Acesse **abapdojo.com**, copie o arquivo `.abap` deste repositório, cole lá e clique em **Run** para ver o resultado.

## 📝 O que aprendi
- Diferença entre estrutura (1 linha) e tabela interna (várias linhas)
- Como declarar e preencher dados
- Como percorrer e ler informações
- Quando usar tabelas internas no desenvolvimento ABAP
